# Asset credits

This is an unofficial fan desktop by Jeyenore. Minecraft and related assets belong to Mojang/Microsoft. This project is not affiliated with or endorsed by them. Inclusion here does not relicense third-party assets.

- `payload/share/minecraft-desktop/vanilla/`: Minecraft Java 1.20.1 textures. Original archive URL and SHA1 are in the included `SOURCE.txt`.
- `payload/share/minecraft-desktop/animals/`: Bedrock animal geometry, animation references and textures; upstream URLs and versions are in the included `SOURCE.txt`.
- `payload/share/minecraft-desktop/lock-sign/`: oak-sign source credits in `SOURCE.txt`, locally generated sign/button SVGs, and village/landscape artwork from the existing setup.
- `ancient-city.png`: reused from the author's Minecraft Dungeons desktop assets. `frozen-river.png` and lock artwork are copied from the existing setup; no standalone redistribution license was supplied with them.
- `lock-village/` and `lock-village-3d/`: alternate lock assets and animation frames retained from the author's setup. The default lock uses the static image referenced in `hyprlock.conf`.
- `payload/share/fonts/minecraft/`: Monocraft and MinecraftRegular font files from the existing setup. [Monocraft upstream](https://github.com/IdreesInc/Monocraft); the original font files did not include license documents in this setup. Check their original distribution terms before public redistribution.
- `payload/share/icons/Tela*`: [Tela icon theme](https://github.com/vinceliuice/Tela-icon-theme), copied with relative symlinks preserved. Retain upstream ownership and license terms.
- `payload/icons/Minecraft-Pixel/`, shell SVG/UI decorations, GTK theme and custom Python shell tools: copied from the author's local desktop work.
- Hyprland and the other installed programs are fetched through their package repositories and retain their upstream licenses.

No blanket license is asserted over this mixed collection. Review third-party redistribution terms before making a public release. Source attribution files supplied with the original assets remain alongside those assets.
